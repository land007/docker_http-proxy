使用说明 / Usage Instructions

HTML 中使用 / Use in HTML:
<span data-i18n="common.save">保存</span>
JavaScript 中使用 / Use in JavaScript:
i18n.t('common.save') // 返回 "Save" 或 "保存"
切换语言 / Toggle Language:
i18n.setLanguage('zh') // 切换到中文 / Switch to Chinese
i18n.setLanguage('en') // Switch to English
